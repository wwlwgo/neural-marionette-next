# 身体施法实验室 · 彩虹能量

方案①的可运行原型：摄像头识别主要身体关节，实时驱动鹿角机甲或骨骼分身；双手塑造彩虹能量球，三个动作节点串成一次救月亮演出。

## 运行

使用 Node 22.12+（已在 Node 24 验证）：

```sh
cd energy-avatar
npm ci
npm run dev
```

打开 http://127.0.0.1:5183/ 。先点击「先看动作演示」查看完整循环；再开启摄像头进行真人演出。无需 API key。

1. 双手在胸前聚拢，保持约 0.25 秒，进入蓄力。
2. 逐渐拉开双手，能量球增大；拉开足够距离后进入上推阶段。
3. 双手举过肩部，保持约 0.25 秒，能量球离手飞向月亮，将月亮托起。
4. 点击「重新施法」再来一次。自动演示中，这个按钮会从头播放。

腿部可见时追踪髋、膝、踝；腿部出画时回退到上半身跟随。展开「分身与跟随设置」可切换骨骼分身检查关节、关闭镜像、调整平滑度和重新居中。

## 实现边界

- MediaPipe Pose Landmarker Lite 在本地 Worker 推理。识别模型和 WASM 本地提供；不上传、录制摄像头影像。
- 固定角色骨段长度，从身体关节方向计算旋转，以模型自身绑定方向进行动作重定向。不是逐关节精确动作捕捉；单摄像头深度、遮挡、转身、手臂交叉仍需真人调试。
- 15 骨骼鹿角机甲，无单独手指骨骼。头部随躯干；未接独立面部或手指追踪。脚部保持地面接触，不实现跳跃位移或物理步行。
- 三个节点按顺序识别，并有持续时间门槛。双手不完整或输入过期时停止节点识别；已释放的动画继续完成。
- 蓄力期间球心绑定实际角色双手中点；拉开改变球体半径；上推后脱离角色，播放本地路径和月亮托举动画。
- 方案③预制片段尚未制作。`createEffects().onNode(callback)` 提供阶段进入事件，可接入预制 GLB 动画或逐帧特效；每次状态进入仅发出一次事件。

## 文件

- `src/pose.js`：上半身与下半身姿态映射、自动示范。
- `src/guardian.js`：GLB 骨骼匹配与姿态重定向。
- `src/spell.js`：三个动作节点、保持判定和连续尺寸控制。
- `src/effects.js`：实时球体、粒子、光环、释放轨迹及预制片段接口。
- `src/tracker.worker.js`：本地身体识别。

## 验证

`npm test` 验证骨段长度、镜像、遮挡、全身回退、节点顺序、重复释放限制、连续尺寸变化和完整自动演示。`npm run build` 验证生产构建。浏览器 `/tests/tracker.html` 可验证 Worker、WASM、模型加载和空白帧推理，且不使用摄像头。

自动输入和空白帧验证不能代替真人摄像头实测。
